# Cadence 用户指南（简体中文）

[返回首页](../README.md) · [English](user-guide.en.md) · [开发指南](development.zh-CN.md)

## 1. Cadence 是什么

Cadence 会把你的打字节奏变成歌曲的一部分。它不会让每个按键从头播放一个声音，而是让人声、伴奏等分离音轨始终共享同一条时间轴：伴奏持续播放，输入活动控制前景声部的显隐。因此你停手时音乐会退回伴奏，继续输入时人声会自然浮现。

桌面版面向 Windows 11。启用后，即使 Cadence 不在前台，你在浏览器、聊天软件、文档编辑器或代码编辑器中输入也能驱动音乐。

## 2. 使用前须知

- **系统**：目前以 64 位 Windows 11 为目标并完成测试。
- **形态**：发布文件是便携版 `.exe`，无需安装；不要把它放进需要管理员权限才能写入的系统目录。
- **音频输出**：确认 Windows 没有静音，并选择了正确的扬声器或耳机。
- **未签名提示**：当前构建未配置代码签名，Windows 可能显示 SmartScreen 警告。只运行你信任来源的文件，并在运行前核对发布页提供的哈希值。
- **全局监听**：只有点击“启用”后才会运行全局键盘监听。暂停音乐不代表停止监听；停止监听请点击“停用”或退出程序。

## 3. 启动与基本使用

1. 将 `Cadence-版本-Windows.exe` 与 `音乐资源` 文件夹保存在同一级目录。
2. 双击运行 Cadence。若 `音乐资源` 不存在，程序会在可执行文件旁自动创建它和示例说明。
3. 在播放列表中选择歌曲，或先导入自己的音乐。
4. 点击顶部“启用”。第一次播放时音频引擎需要解码文件，较大的 WAV 可能需要等待几秒。
5. 切换到任意应用开始输入。界面中的“输入节奏”会显示当前响应。
6. 使用播放区的按钮暂停/继续、切换下一首，或在顺序与随机播放之间切换。
7. 使用结束后点击“停用”；关闭 Cadence 也会停止全局监听。

### 播放控制

| 控件 | 作用 | 注意事项 |
|---|---|---|
| 启用 / 停用 | 开启或关闭 Windows 全局输入监听 | “停用”不会删除音乐文件 |
| 播放 / 暂停 | 控制当前歌曲 | 暂停时全局监听仍可能保持启用 |
| 下一首 | 切换到下一首 | 随机模式下会随机选择另一首 |
| 顺序 / 随机 | 设置自动切歌顺序 | 选择会保存在本机 |
| 播放列表歌曲 | 立即选择歌曲 | 若当前正在播放，会自动播放新歌曲 |
| 音乐资源 | 打开固定资源目录 | 桌面版会自动监听目录变化 |
| `?` | 显示目录和 UVR 快速说明 | 鼠标悬停、键盘聚焦或点击均可查看 |

## 4. 导入音乐

### 4.1 固定目录结构

桌面版只扫描可执行文件旁的 `音乐资源`。根目录下面必须是**歌名文件夹**，音频文件放在对应歌名文件夹中；不要把音频直接放在 `音乐资源` 根目录。

```text
Cadence-0.1.0-Windows.exe
音乐资源/
├─ 示例歌曲/
│  ├─ 示例歌曲_(Vocals).wav
│  └─ 示例歌曲_(Instrumental).wav
└─ 另一首歌/
   ├─ 另一首歌_(Vocals).mp3
   └─ 另一首歌_(Instrumental).mp3
```

推荐操作：

1. 点击播放列表右侧“音乐资源”。
2. 复制 `歌曲名示例` 文件夹。
3. 将副本改成真实歌名。
4. 放入该歌曲的音频或分离音轨。
5. 返回 Cadence；通常一秒左右会自动刷新，不需要重新选择文件夹。

### 4.2 支持的文件

可识别扩展名：

```text
.mp3 .wav .m4a .aac .ogg .opus .flac .webm .mid .midi
```

推荐优先使用 WAV 或高质量 MP3。实际能否解码某种编码取决于 Electron/Chromium 的媒体支持。无损 WAV/FLAC 文件较大，载入时会占用更多内存。

### 4.3 文件如何配对

完整跟手效果至少需要一条人声轨和一条伴奏轨。最稳定的命名是：

```text
歌名_(Vocals).wav
歌名_(Instrumental).wav
```

匹配不区分大小写，也能识别常见关键词：

| 角色 | 可识别关键词示例 |
|---|---|
| 人声 | `Vocals`、`Vocal`、`Vox`、`人声` |
| 伴奏 | `Instrumental`、`No Vocals`、`Accompaniment`、`Backing`、`伴奏` |
| 其他分轨 | `Drums`/`鼓`、`Bass`/`贝斯`、`Other`/`Piano`/`Guitar` |

Demucs 风格也可使用歌名文件夹配合 `vocals.wav`、`drums.wav`、`bass.wav`、`other.wav`。若只有一条普通音频，Cadence 仍可把它作为歌曲播放，但不会得到完整的人声/伴奏跟手显隐效果。若只有一侧分轨，也会按普通音频回退播放。

### 4.4 用 Ultimate Vocal Remover 分离 MP3

Ultimate Vocal Remover（UVR）是独立的第三方开源工具，不包含在 Cadence 中。请从 [UVR 官方网站](https://ultimatevocalremover.com/) 或[官方 GitHub 仓库](https://github.com/Anjok07/ultimatevocalremovergui)获取。UVR 的界面名称可能随版本变化，以下是适合 Cadence 的基准流程：

1. 打开 UVR，`Select Input` 选择原始 MP3。
2. `Select Output` 选择临时输出位置，或直接选择对应的 Cadence 歌名文件夹。
3. `Process Method` 选择 `MDX-Net`。
4. 模型可先使用 `UVR-MDX-NET Inst HQ 3`；不同音乐适合的模型不同，这不是强制要求。
5. 输出格式优先选择 `WAV`。
6. 不要只导出单侧音轨：确保最终同时得到 Vocals 和 Instrumental。若界面有 `Vocals Only` 或 `Instrumental Only`，不要选择只输出其中一侧的配置。
7. 点击 `Start Processing`，等待完成。
8. 将两个输出文件放到同一个歌名文件夹，并按推荐格式命名。

示例：

```text
音乐资源/示例歌曲/示例歌曲_(Vocals).wav
音乐资源/示例歌曲/示例歌曲_(Instrumental).wav
```

如果 UVR 只生成 `Vocals` 与 `No Vocals`，可以保留原名；Cadence 会把 `No Vocals` 识别为伴奏。不要重新剪切其中一条轨道，两个文件必须从同一个时间点开始、保持相同速度和时长，才能同步播放。

## 5. 跟手效果如何工作

- 所有分轨使用同一播放起点和偏移量，始终同步向前。
- 输入不会重新触发人声采样，只会控制前景音量门。
- 连续输入会让人声更稳定地显现；停手后会自然淡出，而不是瞬间切断。
- 空格和回车被视为结构边界，会产生稍明显的触感反馈。
- 前奏或间奏的人声轨本来可能是静音的，这时输入不会凭空制造人声。

这些规则只使用输入时机和类别，不需要知道你输入了什么文字。

## 6. 隐私、权限与联网

### 程序会处理什么

- 启用后，Electron 主进程通过 `uiohook-napi` 接收 Windows 键盘事件。
- 主进程只把事件归为普通键、退格/删除、回车、空格四类。
- 修饰键本身会被忽略。
- 音乐界面只收到类别，不收到原始 keyCode、字符、剪贴板内容或组合后的文本。
- 击键历史不会写入文件、数据库或日志，也不会上传。

### 程序不会做什么

- 不重建或保存你输入的句子。
- 不读取密码框、剪贴板或文档内容。
- 不扫描 `音乐资源` 之外的任意磁盘目录。
- 不上传用户音乐。

### 联网行为

导入的音乐完全在本机读取。采样钢琴首次初始化时，`smplr` 可能从其 CDN 下载音色；网络不可用时自动回退到本地合成器，主要歌曲播放不依赖上传服务。

### 建议

全局键盘钩子属于高敏感权限。只运行可信构建，只在自己拥有或获准使用的设备上启用。若要明确停止监听，请点击“停用”或退出应用，而不是只按暂停。

## 7. 常见问题与排查

### 点击启用后没有音乐

1. 先确认播放列表中已有歌曲并选中了歌曲。
2. 点击播放按钮；浏览器音频系统要求用户交互后才能启动声音。
3. 检查 Windows 音量混合器，确认 Cadence 未静音且输出设备正确。
4. 等待大文件完成解码，尤其是数百 MB 的 WAV。
5. 尝试下一首，以区分是单个文件问题还是全局音频问题。

### 在其他软件中打字没有响应

1. 确认顶部状态是“全局输入已启用”。
2. 不要只按 Ctrl、Alt、Shift、Win 等修饰键；这些键被有意忽略。
3. 某些高权限应用可能隔离来自普通权限进程的全局事件。优先让两个程序使用相同权限级别，不建议日常以管理员身份运行 Cadence。
4. 停用后重新启用，或完全退出并重新打开。

### 音乐资源中有文件，但播放列表没有出现

- 确认音频位于 `音乐资源/歌名/文件`，而不是直接位于根目录。
- 确认扩展名在支持列表内。
- 确认文件不是临时下载文件，且已完成复制。
- 若双轨没有配对，使用推荐的 `(Vocals)` 与 `(Instrumental)` 命名。
- 等待自动刷新；仍无变化时重启 Cadence。

### 只有伴奏，没有人声跟手

- 检查人声文件能否在普通播放器中独立播放。
- 检查两条轨的文件名是否归到同一个歌名。
- 确认人声轨不是 UVR 输出的近乎静音文件。
- 在前奏/间奏中人声本来可能为空，请移动到有人声的段落再测试。

### 两条轨不同步

- 必须使用同一次 UVR 处理得到的两个文件。
- 不要单独裁剪、变速或在文件开头增加静音。
- 两条轨应具有相同的采样长度和起始点；必要时重新从原曲分离。

### 自动刷新失败或文件被占用

- 等待文件复制完成后再测试。
- 关闭仍在写入输出文件的 UVR。
- 避免将程序和资源放到只读、受保护或云盘尚未同步完成的位置。
- 点击“音乐资源”确认 Cadence 实际打开的是你正在修改的目录。

## 8. 更新、迁移与卸载

### 更新

1. 关闭旧版本。
2. 备份 `音乐资源`。
3. 用新 `.exe` 替换旧文件，保留旁边的 `音乐资源`。
4. 启动并检查播放列表。

### 移动到其他电脑或目录

同时复制 `.exe` 和整个 `音乐资源` 文件夹。不要只复制歌名文件夹的一部分，也不要改变人声与伴奏的相对位置。

### 卸载

Cadence 是便携版。关闭程序后删除 `.exe` 即可；若不再需要音乐，也可自行删除 `音乐资源`。播放顺序等少量界面偏好由 Electron/Chromium 保存到当前 Windows 用户的应用数据目录，删除便携文件本身不会自动清除这些偏好。

## 9. 音乐版权

Cadence、UVR 或其他分轨工具不会自动赋予你使用录音的权利。请确认你对原曲、录音、MIDI 和分离后的音轨拥有播放、修改及分发权限。不要把受版权保护的歌曲或分轨提交到源码仓库；项目的 `.gitignore` 已排除常用本地音乐和构建目录，但提交前仍应检查变更列表。
